Predição de Diabetes com KNN

🔍 Visualizar Infográfico Completo (Alta Resolução)

Neste projeto desenvolvi um modelo de classificação utilizando o algoritmo K-Nearest Neighbors (KNN) para prever a ocorrência de diabetes com base em dados clínicos do dataset Pima Indians Diabetes.

Fluxo de Desenvolvimento

Durante o desenvolvimento apliquei todo o fluxo de um projeto de Ciência de Dados:

  • ✔ Coleta e compreensão dos dados
  • ✔ Análise Exploratória (EDA)
  • ✔ Preparação e padronização dos dados
  • ✔ Treinamento do modelo KNN
  • ✔ Avaliação com métricas de desempenho
  • ✔ Predição para novos pacientes
