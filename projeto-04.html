Predição de Churn de Clientes com Árvore de Decisão

🔍 Visualizar Infográfico Completo (Alta Resolução)

Neste projeto desenvolvi um modelo de Machine Learning utilizando o algoritmo Árvore de Decisão (Decision Tree) para prever o risco de cancelamento (Churn) de clientes de uma empresa de telecomunicações. Além de construir o modelo, o objetivo foi compreender quais fatores mais influenciam a decisão de um cliente cancelar ou permanecer, tornando a análise interpretável e útil para apoiar decisões estratégicas.

Fluxo de Desenvolvimento

Durante o desenvolvimento percorri todas as etapas de um projeto de Ciência de Dados:

  • ✔ Coleta e compreensão da base de dados (CustomerChurn)
  • ✔ Tratamento e limpeza dos dados
  • ✔ Análise Exploratória dos Dados (EDA)
  • ✔ Engenharia de atributos e transformação das variáveis categóricas
  • ✔ Treinamento do modelo com Árvore de Decisão
  • ✔ Avaliação utilizando Accuracy, Matriz de Confusão e F1-Score
  • ✔ Análise da importância das variáveis (Feature Importance)
  • ✔ Predição do risco de churn para novos clientes
  • ✔ Interpretação do caminho percorrido pela árvore até a decisão final
