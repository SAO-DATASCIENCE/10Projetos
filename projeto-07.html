Segmentação de Clientes com K-Means

🔍 Visualizar Infográfico Completo (Alta Resolução)

Desenvolvi este projeto de Ciência de Dados aplicando o algoritmo K-Means para segmentar clientes com base em idade, renda anual e comportamento de consumo. O principal aprendizado foi compreender como técnicas de aprendizado não supervisionado podem identificar padrões ocultos nos dados e gerar insights relevantes para marketing e relacionamento com clientes.

Fluxo de Desenvolvimento

Durante o projeto, desenvolvi:

  • ✔ Análise Exploratória de Dados (EDA)
  • ✔ Padronização das variáveis com StandardScaler
  • ✔ Aplicação do Método do Cotovelo para definição do número de clusters
  • ✔ Construção do modelo K-Means
  • ✔ Visualização dos grupos com centróides
  • ✔ Interpretação dos perfis de clientes e recomendações estratégicas para o negócio
