Sistema de Recomendação de Produtos com PCA + K-Means

🔍 Visualizar Infográfico Completo (Alta Resolução)

Desenvolvi esta solução de segmentação de clientes e recomendação de produtos utilizando técnicas avançadas de Aprendizado Não Supervisionado. O projeto demonstra como transformar dados transacionais em informações estratégicas para apoiar ações de marketing, aumentar o engajamento e personalizar a experiência do cliente.

Fluxo de Desenvolvimento

Durante o desenvolvimento foram aplicadas as seguintes etapas:

  • ✔ Engenharia de Atributos (Base por Cliente)
  • ✔ Limpeza e preparação dos dados transacionais
  • ✔ Padronização das variáveis
  • ✔ Redução de dimensionalidade com PCA (Principal Component Analysis)
  • ✔ Clusterização com K-Means e Método do Cotovelo
  • ✔ Visualização dos clusters e centróides
  • ✔ Implementação de sistema de recomendação baseado no comportamento de compra por grupo
