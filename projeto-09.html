Previsão de Séries Temporais (Vendas) com Prophet

🔍 Visualizar Infográfico Completo (Alta Resolução)

Neste projeto desenvolvi uma solução de previsão de vendas utilizando o algoritmo Prophet, com o objetivo de identificar tendências, padrões sazonais e estimar o comportamento futuro das vendas. O modelo apresentou MAPE de 8,29%, demonstrando excelente capacidade preditiva para o horizonte avaliado.

Fluxo de Desenvolvimento

Durante o desenvolvimento foram aplicadas as seguintes etapas:

  • ✔ Análise e preparação de séries temporais
  • ✔ Limpeza e agregação dos dados por período
  • ✔ Análise exploratória e identificação de tendências
  • ✔ Análise de sazonalidade semanal e anual
  • ✔ Construção e treinamento do modelo Prophet
  • ✔ Previsão das vendas para os próximos 30 dias
  • ✔ Avaliação do modelo utilizando MAE, RMSE e MAPE
  • ✔ Análise dos componentes da previsão e interpretação dos resultados

Tecnologias Utilizadas

PYTHON PANDAS NUMPY MATPLOTLIB SEABORN PROPHET GOOGLE COLAB
